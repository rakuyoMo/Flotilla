帆归坞，App 归组。

在 macOS 的 Dock 上增加 “组”：把 App、文件、访达文件夹与网页分类收纳进去，点击组即在 Dock 上方以网格展开，与原生 Dock 文件夹一样。

简介

原生的 Dock 文件夹只能放在 Dock 右侧，而且每一个都是磁盘上的一个文件夹。归帆（Flotilla）把 “组” 放进 Dock 左侧的 App 区域。

  • 组由归帆自己保存，不对应磁盘上的文件夹，收纳进去的 App 都留在原处。

  • 像 Dock 右侧区域那样，组里也可以放文件、访达文件夹与网页。

  • 点击组，它会在 Dock 上方以网格展开；外观、动效与位置一比一还原原生 Dock 文件夹的网格样式。

功能

App、文件、访达文件夹与网页，分类收纳进组。

访达文件夹像叠放那样展开

点击访达文件夹，在同一个面板里浏览其中的内容，文件显示内容缩略图，网格末尾是 “在访达中打开”。

  • 返回按钮回到上一层
  • 设置里可以打开显示隐藏文件

拖进来就加入

把 App、文件与访达文件夹拖到 Dock 上组的 tile 上，或把它们连同网页拖到设置窗口的组上。

在设置窗口里管理组

  • “添加…” 弹出菜单：“添加 App…” “添加文件…” “添加网页…”
  • 双击组即可重命名
  • 拖动行来调整顺序，或移进其它组
  • 右键点按或按住 Control 点按一行，弹出更多操作

  • 与 App 并排的组

    每个顶层的组在 Dock 的 App 区域里都有自己的 tile，名称就是组名。

  • App、文件、访达文件夹与网页

    在一个组里随意混放；文件用默认 App 打开，网页用默认浏览器打开。

  • 组可以嵌套

    组里还能放组；在面板里点击子组即可进入，返回按钮回到上一层。

  • 与 Dock 文件夹一样的网格

    点击 tile，组在 Dock 上方展开，尾巴指向 tile。

  • 实时渲染的组图标

    tile 显示组内前几项的图标，数量可选，最多 4 个；底板跟随系统的浅色、深色外观。

  • 在面板里直接整理

    拖动调整顺序；把一项拖出面板，停到浮出 “移除” 再松开，即从组里删除，就像把图标拖离 Dock。

  • 跟随移动与更新

    App 与文件移动或改名后，组里的这一项自动跟到新位置；App 更新后仍打开装好的那一份。

  • 不打扰

    归帆在后台运行，只有一个状态栏图标；展开面板时 Dock 上不出现归帆，也不抢走当前 App 的焦点。

  • 五种语言

    英文、简体中文、繁体中文、日文、韩文，跟随系统语言；其它语言显示英文。

工作原理

每个顶层的组，都有一个占位 App。

Dock 只能放 App 与文件，所以归帆为每个顶层的组生成一个占位 App，放进 Dock；它的图标就是组图标。

  1. 1

    点击组的 tile

    点击 tile 时 Dock 启动占位 App。

  2. 2

    占位 App 打开 flotilla:// URL

    它不把任何 App 带到前台，打开 URL 后随即退出。

  3. 3

    归帆展开或收起面板

    归帆没有运行时，系统会先启动它。拖到 tile 上的项也经同样的途径交给归帆。

归帆对你的 Mac 做了什么

  • 只动自己的 tile

    归帆通过修改 Dock 偏好（com.apple.dock）把 tile 加到 Dock 上。

    只增删改归帆自己的 tile，位于 persistent-apps，即 Dock 左侧的 App 区域；其它 tile 与 Dock 的其它设置都不动。

  • 每次改动后重启 Dock

    每次改动后结束 Dock 进程，由系统自动重新启动 Dock，改动随之生效。

  • 第一次改动前先备份

    每次运行中第一次改动之前，先把整个 com.apple.dock 偏好导出备份，最多保留最新的 5 份。

    ~/Library/Application Support/Flotilla/Backups/com.apple.dock-<yyyyMMdd-HHmmss>.plist

  • 数据与设置

    数据保存在 ~/Library/Application Support/Flotilla：

    • folders.json：组的数据
    • DockTiles/：代表每个根组放进 Dock 的占位 App
    • Backups/：Dock 偏好的备份

    设置保存在偏好设置域 com.rakuyo.flotilla。

  • 只为网页标题联网

    归帆只在 “添加网页…” 与 “编辑…” 的提示框里获取网页标题时联网。

常见问题

你可能想知道的。

更多细节见 README。

为什么 macOS 提示无法验证归帆，不让打开？

归帆没有经过 Apple 公证。第一次打开时，系统会提示 Apple 无法验证它是否包含恶意软件，并拒绝打开。

点击 “完成” 关闭提示，打开 “系统设置 › 隐私与安全性”，向下滚动到 “安全性”，点击 “仍要打开”。这个按钮只在尝试打开归帆之后的一小时内出现。

查看安装指南 →

不给辅助功能权限能用吗？差别在哪？

没有这项权限时仍然可以使用，区别是：

  • 面板以点击时鼠标所在的位置为准摆放，不一定正好对准 tile
  • 要等 Dock 启动 tile 之后面板才会出现，比有权限时稍慢
换用新版本后，为什么要重新授权？

归帆使用 ad-hoc 签名，换用新版本后，原来的授权可能失效，需要重新授权。

授权的位置是 “系统设置 › 隐私与安全性 › 辅助功能”；macOS 27 里这一页是 “隐私与安全 › 设备控制和数据访问”。

Dock 为什么会重启？

归帆通过修改 Dock 偏好把 tile 加到 Dock 上。每次改动后结束 Dock 进程，由系统自动重新启动 Dock，改动随之生效。

更新 tile 的图标也是这样的改动，所以组的预览变化、系统切换浅色与深色外观时，Dock 都会重启。

怎么把组的 tile 从 Dock 上去掉，又怎么放回来？

要去掉组的 tile，像其它 App 那样把它拖出 Dock 即可。

归帆不会自己把它加回去：这个组在设置窗口里标出 “不在 Dock 上”，在它的右键菜单里点 “添加到 Dock” 即可加回。

支持哪些 Mac？

归帆需要 macOS 15 或更高版本，以及搭载 Apple 芯片的 Mac。

支持哪些语言？

英文、简体中文、繁体中文、日文、韩文，跟随系统语言；其它语言显示英文。

App 名在简体中文下显示为 “归帆”，繁体中文下为 “歸帆”，日文下为 “帰帆”，其它语言下为 “Flotilla”。
