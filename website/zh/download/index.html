GitHub 上的全部版本

在 GitHub 上选择 “Watch › Custom › Releases”，有新版本时就会收到通知。

安装

分三步装好归帆。

  1. 1

    解压，拖进 “应用程序”

    双击下载好的 Flotilla-X.Y.Z.zip 解压，把 Flotilla.app 拖到 “应用程序” 文件夹。

    访达按系统语言显示它的名称，简体中文下为 “归帆”。

    归帆
    应用程序
  2. 2

    第一次打开

    归帆没有经过 Apple 公证。第一次打开时，系统会提示 Apple 无法验证它是否包含恶意软件，并拒绝打开。

    点击 “完成” 关闭提示，然后按以下步骤放行：

    1. 打开 “系统设置 › 隐私与安全性” macOS 27 里这一页是 “隐私与安全”
    2. 向下滚动到 “安全性”，在提示这个 App 已被阻止的那一行点击 “仍要打开” 这个按钮只在尝试打开归帆之后的一小时内出现
    3. 按提示输入登录密码确认

    之后归帆就能像其它 App 一样正常打开。

    也可以在终端里移除它的隔离属性，之后直接打开：

    xattr -d com.apple.quarantine /Applications/Flotilla.app
    为什么 macOS 会拦下归帆？

    归帆使用 ad-hoc 签名，没有经过 Apple 公证，Apple 无法验证它是否包含恶意软件，所以系统第一次会拒绝打开它。

    macOS 怎样检查要打开的 App、怎样仍要打开，Apple 在 在 Mac 上安全地打开 App 一文里有说明。

    完成
    安全性
    仍要打开
  3. 3

    授予辅助功能权限

    归帆通过辅助功能读取 Dock 的界面信息，用来：

    • 找到组的 tile（Dock 上的一个图标）在屏幕上的位置，让面板和它的尾巴对准 tile
    • 识别鼠标在 tile 上的点击，在抬起的一刻就展开，与系统自带的 Dock 文件夹时机一致

    没有这项权限时，每次启动归帆后第一次点击 tile，系统会弹出授权提示。授权的位置是 “系统设置 › 隐私与安全性 › 辅助功能”；macOS 27 里这一页是 “隐私与安全 › 设备控制和数据访问”。

    没有这项权限时

    仍然可以使用，区别是：

    • 面板以点击时鼠标所在的位置为准摆放，不一定正好对准 tile
    • 要等 Dock 启动 tile 之后面板才会出现，比有权限时稍慢

    换用新版本后

    归帆使用 ad-hoc 签名，换用新版本后，原来的授权可能失效，需要重新授权。

文件与文件夹

访达文件夹如果在 “文稿” “桌面” “下载” 等位置，面板第一次展开它时，系统会先询问是否允许访问。归帆要读取文件夹的内容，才能在面板里展开它。

快速上手

创建第一个组。

归帆待在状态栏里，图标是一艘帆船。点击它并选择 “设置…” 打开设置窗口；同一个菜单里还有 “退出归帆”。

新建组

  1. 在 “组” 下点击 “新建组”，输入名称后按回车 Dock 的 App 区域随即出现这个组的 tile；Dock 会短暂重启来显示它
  2. 选中这个组，点击 “添加…”，选择 “添加 App…” “添加文件…” 或 “添加网页…”
  3. 也可以把 App、文件与访达文件夹拖到设置窗口里的组上，或拖到 Dock 上这个组的 tile 上；网页从浏览器拖到设置窗口里的组上

使用面板

  • 点击组的 tile 展开面板，点击其中一项即可打开
  • 点击子组或访达文件夹即可进入；返回按钮回到上一层
  • 再次点击 tile、点击别处或按 Esc，面板收起
  • 在组里拖动一项，调整它的位置
  • 把一项拖出面板，停在那里直到浮出 “移除”，松开即从组里删除

完整的使用说明见 README

从源码构建

自己动手构建。

只需要 Xcode Command Line Tools 与 mise，不需要安装 Xcode。

  • Xcode Command Line Tools 26 或更高版本

    26 版带有 Swift 6.2 与 macOS 26 SDK；面板在 macOS 26 上用到的 NSGlassEffectView 只在这个 SDK 里才有。

  • mise

    构建命令都是 mise.toml 里的任务。

git clone https://github.com/rakuyoMo/Flotilla.git
cd Flotilla

# 编译 release 版本，打包为 build/Flotilla.app 并 ad-hoc 签名
mise run bundle

# 启动打包好的 App
open build/Flotilla.app
  • 编译时的两条 ld: warning: search path ... not found 可以忽略：它们指向 Command Line Tools 里本来就没有的目录。
  • 启动 build/Flotilla.app 之前，先退出已安装的归帆：归帆已在运行时，新启动的那一份会激活已在运行的那一份，然后立即退出。

测试、代码规范等更多内容见 README
