### 新機能

- グループはDockの左側にアプリと並んで表示され、それぞれ固有の名前と、項目を最大4つまでプレビューするアイコンを持ちます
- グループには、アプリ、ファイル、フォルダ、Webページ、サブグループを入れられます
- グループをクリックすると、Dock標準のフォルダと同じ見た目とアニメーションで、Dockの上にグリッドが開きます
- フォルダは同じパネルの中でファイルのサムネール付きで開き、グリッドには「Finderで開く」があります
- アプリ、ファイル、フォルダは、Dockや設定ウインドウのグループにドロップして追加できます。Webページは設定ウインドウにドロップできます
- パネルの項目はドラッグで並べ替えられます。削除するには、項目をパネルの外にドラッグし、「削除」が表示されてから離します
- アプリやファイルを移動したり名前を変更したりしても、グループから開けます。アプリのアップデート後は、新しくインストールされたバージョンを帰帆が開きます
- 帰帆はメニューバーで動作してDockには表示されず、パネルが使用中のアプリからフォーカスを奪うこともありません
- GitHub Releasesで毎日、または「アップデートを確認…」でアップデートを確認します。アップデートを自動でダウンロードし、終了時にインストールすることもできます
- 英語、簡体字中国語、繁体字中国語、日本語、韓国語に対応しています
