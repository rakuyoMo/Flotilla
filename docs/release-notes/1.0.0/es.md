### Novedades

- Los grupos se colocan a la izquierda del Dock junto a tus apps, cada uno con su propio nombre y un icono que muestra una vista previa de hasta cuatro de sus ítems
- Un grupo puede contener apps, archivos, carpetas, páginas web y subgrupos
- Haz clic en un grupo para abrir una cuadrícula sobre el Dock, con el mismo aspecto y las mismas animaciones que las carpetas integradas del Dock
- Las carpetas se abren en el mismo panel con miniaturas de los archivos, y la cuadrícula incluye **Abrir en el Finder**
- Suelta apps, archivos o carpetas sobre un grupo en el Dock o en la ventana de ajustes para añadirlos; las páginas web se pueden soltar en la ventana de ajustes
- Arrastra los ítems del panel para reordenarlos; para eliminar uno, arrástralo fuera del panel, espera a que aparezca **Eliminar** y suéltalo
- Las apps y los archivos se siguen abriendo desde un grupo aunque los muevas o les cambies el nombre, y tras actualizar una app, Flotilla abre la versión recién instalada
- Flotilla funciona en la barra de menús sin aparecer en el Dock, y los paneles no le quitan el foco a la app que estás usando
- Busca actualizaciones en GitHub Releases cada día o con **Buscar actualizaciones…**, y puede descargarlas automáticamente e instalarlas al salir
- Disponible en inglés, chino simplificado, chino tradicional, japonés y coreano
