### 새 기능

- 그룹이 Dock 왼쪽에 앱과 나란히 놓이며, 각 그룹에는 고유한 이름과 함께 항목을 최대 4개까지 미리 보여 주는 아이콘이 있습니다
- 그룹에는 앱, 파일, 폴더, 웹 페이지와 하위 그룹을 넣을 수 있습니다
- 그룹을 클릭하면 Dock 위에 격자가 열리며, 모양과 애니메이션은 Dock에 내장된 폴더와 같습니다
- 폴더는 같은 패널 안에서 파일 썸네일과 함께 열리며, 격자에는 ‘Finder에서 열기’가 있습니다
- 앱, 파일 또는 폴더를 Dock이나 설정 윈도우의 그룹에 드래그하여 놓으면 추가됩니다. 웹 페이지는 설정 윈도우에 놓을 수 있습니다
- 패널에서 항목을 드래그하여 순서를 바꿀 수 있습니다. 항목을 제거하려면 패널 밖으로 드래그하고 ‘제거’가 나타날 때까지 기다린 다음 놓으면 됩니다
- 앱과 파일을 이동하거나 이름을 변경해도 그룹에서 계속 열 수 있으며, 앱이 업데이트되면 Flotilla가 새로 설치된 버전을 엽니다
- Flotilla는 메뉴 막대에서 실행되며 Dock에는 나타나지 않고, 패널은 현재 사용 중인 앱의 포커스를 가져가지 않습니다
- 매일 또는 ‘업데이트 확인…’을 선택할 때 GitHub Releases에서 업데이트를 확인하며, 업데이트를 자동으로 다운로드하고 종료 시 설치할 수 있습니다
- 영어, 중국어(간체), 중국어(번체), 일본어, 한국어로 제공됩니다
