### Nouveautés

- Les groupes s’affichent dans la partie gauche du Dock, à côté de vos apps, chacun avec son propre nom et une icône qui présente jusqu’à quatre de ses éléments en aperçu
- Un groupe peut contenir des apps, des fichiers, des dossiers, des pages web et des sous-groupes
- Cliquez sur un groupe pour ouvrir une grille au-dessus du Dock, avec la même apparence et les mêmes animations que les dossiers intégrés du Dock
- Les dossiers s’ouvrent dans le même panneau avec des miniatures des fichiers, et la grille comprend **Afficher**, qui ouvre le dossier dans le Finder
- Déposez des apps, des fichiers ou des dossiers sur un groupe dans le Dock ou dans la fenêtre des réglages pour les ajouter ; les pages web peuvent être déposées dans la fenêtre des réglages
- Faites glisser les éléments du panneau pour les réorganiser ; pour en supprimer un, faites-le glisser hors du panneau, attendez que **Supprimer** apparaisse, puis relâchez-le
- Les apps et les fichiers s’ouvrent toujours depuis un groupe après avoir été déplacés ou renommés, et après la mise à jour d’une app, Flotilla ouvre la version nouvellement installée
- Flotilla s’exécute dans la barre des menus sans apparaître dans le Dock, et les panneaux ne retirent pas le focus à l’app que vous utilisez
- Recherche les mises à jour sur GitHub Releases chaque jour ou avec **Rechercher les mises à jour…**, et peut les télécharger automatiquement et les installer en quittant
- Disponible en anglais, chinois simplifié, chinois traditionnel, japonais et coréen
