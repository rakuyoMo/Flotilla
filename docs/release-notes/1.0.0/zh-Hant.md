### 新增

- 組和 App 並排顯示在 Dock 左側，每個組都有自己的名稱和圖像，圖像會預覽組裡的前幾項，最多 4 個
- 組裡可以放 App、檔案、檔案夾、網頁和子組
- 按一下組圖像，組會在 Dock 上方以格狀展開，外觀和動畫與 Dock 內建的檔案夾一致
- 檔案夾可以直接在目前的面板裡展開，並顯示檔案縮覽圖，排在最後的是 “在Finder裡打開”
- 把 App、檔案或檔案夾拖到 Dock 上的組圖像或設定視窗裡的組，就能加入進去；網頁也可以拖到設定視窗裡加入
- 在面板裡拖移項目可以排序；要移除某個項目，把它拖出面板，等 “移除” 提示出現後放開
- 移動或改名後，App 和檔案仍能從組裡打開；App 更新後，歸帆也會打開已安裝的新版本
- 歸帆在選單列執行，不會在 Dock 上多出歸帆的圖像，展開面板時也不會搶走目前 App 的焦點
- 每天或按一下 “檢查更新…” 時，到 GitHub Releases 檢查更新，還可以自動下載更新並在結束時安裝
- 支援英文、簡體中文、繁體中文、日文和韓文
