### 新增

- 组和应用并排显示在 Dock 左侧，每个组都有自己的名称和图标，图标会预览组里的前几项，最多 4 个
- 组里可以放应用、文件、文件夹、网页和子组
- 点击组图标，组会在 Dock 上方以网格展开，外观和动画与 Dock 自带的文件夹一致
- 文件夹可以直接在当前面板里展开，并显示文件缩略图，网格末尾有 “在访达中打开”
- 把应用、文件或文件夹拖到 Dock 上的组图标或设置窗口里的组，就能添加进去；网页也可以拖到设置窗口里添加
- 在面板里拖动项目可以排序；要移除某一项，把它拖出面板，等 “移除” 提示出现后松手
- 移动或改名后，应用和文件仍能从组里打开；应用更新后，归帆也会打开已安装的新版本
- 归帆在菜单栏运行，不会在 Dock 上多出归帆的图标，展开面板时也不会抢走当前应用的焦点
- 每天或点击 “检查更新…” 时，到 GitHub Releases 检查更新，还可以自动下载更新并在退出时安装
- 支持英文、简体中文、繁体中文、日文和韩文
