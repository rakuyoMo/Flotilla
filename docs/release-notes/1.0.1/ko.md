### 새 기능

- 새 버전이 있으면 업데이트 윈도우에 해당 버전의 변경 사항이 앱의 언어로 표시됩니다

### 개선

- Finder 폴더가 Finder에서 보이는 실제 모습 그대로 표시됩니다. 태그 색상과 이모지 또는 기호도 반영됩니다. 패널, 설정 윈도우, 그룹 아이콘, 패널에서 펼친 하위 폴더 모두 마찬가지이며, 모습이 바뀌면 바로 업데이트됩니다
- ‘최신 버전입니다.’ 알림의 ‘버전 기록’ 버튼을 누르면 이제 공식 웹사이트의 릴리스 노트(영어)가 열립니다

### 수정

- 앱을 종료한 후에도 백그라운드 프로세스가 남아 있으면 그룹에서 해당 앱을 클릭해도 아무 반응이 없던 문제를 수정했습니다. 이제 그룹의 앱이 다른 위치에서 실행 중인 같은 앱의 다른 프로세스로 대체되지 않으며, Dock이나 Finder에서 열 때와 같이 실행됩니다
