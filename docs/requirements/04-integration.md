# 04 集成验收

先读 [00 总览](00-overview.md) 与 01–03 三份文档，并以 03 阶段合入后的代码为基线。本阶段不新增功能，只做端到端验证、清理与文档回写。

## 端到端验证

在真实 Dock 上按下面顺序走一遍，每一步记录结果：

1. `mise run bundle`，`open build/Flotilla.app`：Dock 上没有 Flotilla；状态栏有图标
2. 设置窗口新建根文件夹“工作”，加入两个 App，再在其中新建子文件夹“工具”并加入一个 App
3. Dock 出现“工作”tile，图标含 App 预览；把预览数量改为 0，图标只剩底板；改回 4
4. 点击 tile：面板立即展开，位置与尾巴对准 tile；前台 App 保持前台
5. 再次点击 tile：收起。展开后点击桌面、点击其它窗口、点击 Dock 上其它 App：都收起
6. 展开后点击“工具”：进入子层级，出现返回按钮与标题；返回；Esc 收起
7. 展开后点击某个 App：该 App 启动，面板收起
8. 重命名“工作”为“日常”：tile 名更新；删除“日常”：tile 消失，stub 目录被清理
9. 退出 Flotilla 后点击残留或新建的 tile：Flotilla 被拉起并展开面板
10. 切换系统外观（深色 ↔ 浅色）后 Dock 与面板的图标都换成对应外观的版本；Dock 重启一次
11. 完成后清理测试数据，Dock 偏好与开始前一致（比对备份）

无法在当前环境验证的步骤，明确写“未验证”与原因，不得写成通过。
