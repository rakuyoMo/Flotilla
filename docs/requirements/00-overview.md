# Flotilla 需求总览

本目录是 Flotilla 的需求文档。`00` 是总览与公共约定，`01`–`12` 是按实现顺序拆分的十二个阶段，每个阶段由一名实现者独立完成。

## 目标

在 Dock 左侧的 App 区域放置 “组”，把 App 分类收纳进去；像 Dock 右侧区域那样，组里也可以放文件、访达文件夹与网页，访达文件夹在面板里像叠放那样展开其中的内容。

点击组，在 Dock 上方以 “网格” 样式展开其中的内容；展开后的交互、动效与位置以 macOS 原生 Dock 文件夹（原生文件夹只能放在 Dock 右侧区域，查看方式为网格）为准，一比一还原。

原生行为里明确**不做**的两处：

- 组的展开内容中不提供 “在访达中打开”；访达文件夹展开后有这一格，与原生一致（需求 20）
- 展开时 Dock 上的组图标不做外观变化

## 需求清单

后续文档用 “需求 N” 引用。

1. 允许组嵌套。
2. Dock 上的组图标要实时渲染出组内前几项的图标：App、文件与网页都算，跳过子组（见 07）。上限在 App 内写死为 4，用户可在 0–4 之间调整；0 表示只显示组图标。
3. 点击 Dock 上的组图标，固定按 “网格” 样式展开内容；动效与位置与原生一比一还原。
4. 组的展开内容中不提供 “在访达中打开”；访达文件夹展开后有这一格（需求 20）。
5. 展开状态下再次点击该图标，收起；展开状态下点击其它区域或其它 App，也收起。
6. 展开内容时，Dock 上不出现 Flotilla 的活动图标。
7. 提供一个状态栏图标，用于快速打开设置页面。
8. 展开时 Dock 上的组图标不需要变化。
9. 点击展开内容中的 App 图标，直接启动该 App，同时收起展开内容。
10. tile 被拖出 Dock 后，设置窗口显示状态标识，并允许重新添加到 Dock；“添加到 Dock” 在组这一行的右键菜单里（需求 25）。
11. 把 App 图标拖到 Dock 上的组图标上，即把该 App 加入这个组。
12. 界面支持英文、简体中文、繁体中文、日文、韩文。
13. 设置窗口里的组图标用固定图标，不渲染其中的 App 图标。
14. 组里还可以放文件与网页，像 Dock 右侧区域那样：把文件从访达拖到设置窗口的组上或 Dock 上的组图标上，把网页从浏览器拖到设置窗口的组上，点击后用默认 App 或浏览器打开。
15. 访达文件夹可以像文件一样作为一项放进组，点击后在面板里展开它的内容（见 08）。
16. 设置窗口提供 “添加文件…”，选择文件与访达文件夹加入组；它在 “添加…” 的菜单里（需求 24）。
17. 组图标的预览（需求 2）也显示文件与网页的图标。
18. 文件移动或改名后，组里的这一项自动跟到新位置。
19. App 移动或改名后，组里的这一项同样自动跟到新位置。
20. 点击访达文件夹，像 Dock 叠放那样在面板里展开它的内容，网格末尾有 “在访达中打开”。
21. 设置窗口里，访达文件夹这一行在名称后标出所在位置。
22. App 更新后，组里的这一项仍打开装好的那一份。
23. 设置里提供开关，访达文件夹在面板里展开时显示隐藏文件。
24. 设置窗口的 “添加 App…” “添加文件…” 两个按钮合并为一个 “添加…”，点击后弹出菜单：“添加 App…” “添加文件…” “添加网页…”；“添加网页…” 弹出提示框，输入网址与可选的标题后把网页加入选中的组（需求 31）；标题可以不填，留空时自动获取网页的标题。
25. 设置窗口的组树支持右键菜单：组有 “添加到 Dock” 与 “删除”；App、文件与访达文件夹有 “在访达中显示” 与 “删除”；网页有 “在默认浏览器中打开” “编辑…” 与 “删除”，“编辑…” 弹出 “添加网页…” 的提示框，修改网页的网址与标题。按钮行的 “添加到 Dock” 与 “删除” 由右键菜单里的这两项代替。
26. 面板里把组的一项拖出面板，即从组里删除这一项；剩下的项按原来的顺序补上空位。删除要等 “移除” 浮出之后松开（需求 28）。
27. 面板里拖动组的项，调整它们在组里的顺序。
28. 面板里把一项拖出面板后，像拖离 Dock 那样，拖出一段距离、拖动满一会儿，图标上方浮出 “移除”，这之后松开才从组里删除；“移除” 浮出之前松开，这一项落回原位。
29. Flotilla 的分组叫 “组”，免得与访达文件夹混淆，如 “新建组” “组图标内显示的图标数量”；五种语言的界面文字与注释、变量名一并这样叫。
30. 访达里的文件夹叫 “访达文件夹”。
31. 设置窗口里，只有选中组时 “添加…” 可用；选中 App、文件、访达文件夹与网页时禁用。
32. 设置窗口里，选中组或没有选中项时 “新建组” 可用；选中 App、文件、访达文件夹与网页时禁用。
33. 设置窗口里，网页这一行像访达文件夹标出位置那样，在名称后标出网址。
34. 网址里的中文等可见非 ASCII 字符按解码后的文字显示：设置窗口网页行标出的网址、没有标题时网页的名称、网页 “编辑…” 提示框里填好的网址。

初版不给用户更多选择：除需求 2 的数量设置与需求 23 的显示隐藏文件开关外，不增加任何其它设置项，不提供网格以外的展示样式。

## 术语

| 术语 | 含义 |
|---|---|
| 组 | Flotilla 管理的分组，收纳 App、文件与网页，可嵌套；数据由 Flotilla 自己保存，不对应磁盘目录 |
| 访达文件夹 | 磁盘上的目录，不含文件包；作为一项放进组时与文件同类（需求 15），在面板里点击时展开（需求 20） |
| 根组 | 没有父组的组；每个根组对应 Dock 上的一个 tile |
| tile | Dock 上的一个图标 |
| stub | 代表根组放进 Dock 的占位 App bundle，点击它即触发展开 |
| 面板 | 点击 tile 后在 Dock 上方展开的网格弹窗 |
| 预览图标数 | 需求 2 中渲染进组图标的图标数量上限，0–4；App、文件与网页都算 |

## 总体方案

Flotilla 是一个无 Dock 图标的常驻后台 App（`LSUIElement`），只有状态栏图标与设置窗口。

- **Dock 集成**：Dock 只能放 App 与文件，因此每个根组对应一个由 Flotilla 生成的 stub App bundle，写入 Dock 偏好（`com.apple.dock`）左侧 App 区域后重启 Dock 使其出现。
  - stub 的图标即按需求 2 渲染的组图标。
- **点击信号**：点击 tile 时 Dock 启动 stub；stub 以不激活任何 App 的方式打开 `flotilla://folder/<根组 id>`，随即退出。
  - Flotilla 作为该 URL scheme 的处理者收到事件，展开或收起面板。
  - Flotilla 未运行时，Launch Services 会先启动它。
- **面板定位**：通过 Accessibility API 读取 Dock 进程里该 tile 的屏幕位置与尺寸，面板居中对准 tile。
  - 未获得辅助功能权限时，退化为以收到点击信号时的鼠标位置为锚点。
- **面板本身**：不激活 Flotilla 的悬浮面板（`NSPanel`，nonactivating），窗口层级高于 Dock；外观、几何、动效对照原生逐项还原。
- **联网**：只在网页的提示框（“添加网页…” 与网页的 “编辑…”）获取网页标题时联网，访问的是用户输入的网址（系统的 LinkPresentation，见 09、10）。
  - Info.plist 只为网页内容放开明文 HTTP（`NSAllowsArbitraryLoadsInWebContent`），让 `http://` 网页也取得到标题。

## 模块划分

App 的代码在 `Sources/Flotilla/` 下，按职责分子目录；stub 的可执行文件在 `Sources/FlotillaDockTile/`；每个文件一个类型。

下表是各阶段共同遵守的接口契约，类型名与职责不得私自更改；实现细节由各阶段文档规定。

| `Model/` | `Group` | 组：`id`、`name`、`items` | 01 |

12. [12 改称 “组”、按钮的可用条件与网页的网址](12-groups.md)：Flotilla 的分组改称 “组”、访达里的文件夹改称 “访达文件夹”；“添加…” 只在选中组时可用，“新建组” 在选中组或没有选中项时可用；设置窗口的网页行在名称后标出网址；网址里的中文按解码后的文字显示

## 公共约束

- 遵守 [AGENTS.md](../../AGENTS.md) 的全部规范，特别是 “产物可追溯性” 一节：需求之外的东西不写进代码。
- 新建或编辑 `.swift` 文件后必须运行 `mise run swift:lint`，不通过就 `mise run swift:format` 后再查。
- 纯逻辑（模型、持久化、几何计算、plist 条目构造）必须有 Swift Testing 单元测试，`swift test` 全部通过。
- 拿不准或靠推测写下的地方，用 `#warning("TODO: ...")` 标记，并在完成汇报里列出。
- 修改 Dock 偏好之前必须先备份 `com.apple.dock`；只增删 Flotilla 自己的 tile，不碰其它任何 tile。
  - 唯一例外是 03 阶段测量用的临时原生文件夹 tile，测完必须删除。
- 不得修改 Dock 的其它偏好（自动隐藏、放大、尺寸、位置等）。
- 不增加需求清单之外的设置项、菜单项与功能。
